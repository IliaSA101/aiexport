# ТЗ: свой инструмент упаковки кода (Go)

> Составлено 13.08.2026 по итогам разбора. Обоснование каждой фичи — в `00_КОНТЕКСТ.md`.
> Рабочее название не выбрано. Módule path после регистрации репозитория: `go mod init github.com/<user>/<name>`.

## Позиционирование

Не «замена repomix». repomix закрывает обычный сценарий (один корень, конфиг в репозитории) полностью — для таких проектов свой инструмент не нужен и писать его незачем.

Свой инструмент нужен там, где repomix объективно слаб:
1. **Мультикорневые бандлы** — сборка из произвольных путей разных корней с человеческими подписями (кейс Битрикса: `/local/modules/x` + `/local/docs` + куски ядра).
2. **Профили в UI** — быстрый выбор нарезки мышкой, без правки JSON.
3. **Пикер по ФС удалённого сервера** — зашёл через туннель, потыкал, выгрузил.
4. **Ноль зависимостей** — один бинарник вместо Node.js.

## Технические решения

| Вопрос | Решение |
|---|---|
| Язык | Go 1.26+ |
| Распространение | Один статический бинарник, кросс-компиляция `GOOS=windows/linux/darwin` |
| UI | HTML+JS, вшитый через `embed.FS`. Без сборки фронта |
| Глобы | `bmatcuk/doublestar` |
| Токены | `pkoukk/tiktoken-go`, кодировка `o200k_base` |
| Секреты | Правила `gitleaks` (тоже Go, подключается библиотекой) |
| Git | вызов `git` или `go-git` |
| AST-сжатие | **В v1 нет.** См. `00_КОНТЕКСТ.md` §3 про cgo/wazero/регулярки |

## Режимы запуска

Один бинарник, три режима:

1. **`aiexport`** — поднимает `127.0.0.1:8471`, открывает браузер, показывает форму. На Windows — двойной клик по `.exe`. Перетаскивание папки на `.exe` → экспорт с дефолтами.
2. **`aiexport --config .aiexport.yaml --out ./export.md`** — headless для CI/git-хуков.
3. **`aiexport serve --host 127.0.0.1 --port 8471 --token SECRET`** — на сервере без GUI, доступ через SSH-туннель.

**Безопасность:** инструмент читает произвольные файлы ФС. Дефолт — только loopback + токен. Наружу не вешать.

## Конфигурация

Два уровня:
- **`.aiexport.yaml` в корне проекта** — профили проекта, лежит в репозитории, едет с ним.
- **`%APPDATA%\aiexport\profiles.yaml`** (или `~/.config/`) — глобальная история, как сейчас в `CUserOptions`.
- **Portable-режим:** если рядом с `.exe` лежит `profiles.yaml` — использовать его, профиль пользователя не трогать (запуск с флешки).

## Функционал v1 (приоритет по убыванию)

### 1. `.gitignore` + дефолтный ignore-лист — КРИТИЧНО
Без этого первый же локальный запуск бесполезен. Замер url-shortener: 12 531 файл в дереве, из них 12 117 (96,7%) — `vendor` + `node_modules`. Сейчас их отфильтровывает GitHub в обходном маршруте; при локальном запуске фильтровать некому.

Плюс встроенный список: `.git`, `node_modules`, `vendor`, `dist`, `build`, `.venv`, `__pycache__`, `.obsidian`.

### 2. Фильтрация: чёрный список, а не whitelist расширений
Текущий скрипт берёт содержимое только у разрешённых расширений — остальное попадает **пустым именем**, и модель считает, что содержимое ей показали. На url-shortener так потерялись 11 файлов, включая `docker/nginx/default.conf`.

Правильно: брать всё текстовое, отсекая
- бинарники — sniff на NUL-байт в первых 512 байтах,
- файлы больше лимита размера,
- явный мусор глобами.

### 3. Исключения через глобы
Сейчас — только точное совпадение или префикс `path + '/'` (`adeAIAnalytics.php:126-131`). Нельзя написать `**/node_modules/**` или `*.min.js`.

### 4. Счётчик токенов с зонами
Не «размер файла 1,2 МБ», а зелёная / жёлтая / красная зона по порогам **личного опыта**, а не по спецификации модели. Целевой бюджет ~100k. Дерево с токенами по папкам — как `--token-count-tree` у repomix.

### 5. Отчёт «попало в список, но без содержимого»
Списком, прямо в UI после сборки. Ловит класс тихих потерь из п.2. Такого нет ни у кого.

### 6. Управление порядком
Релевантное — в конец, вплотную к вопросу. Замер на большом рабочем бандле: те же файлы на позиции 95% работали, на позиции 22% — нет. Стрелки «вверх/вниз» у строк + подсказка. Опционально — сортировка по частоте изменений в git (как `sortByChanges`).

### 7. Режим на каждый путь: полностью / скелет / только дерево
Ключевая фича, которой нет ни у кого: у repomix `--compress` глобальный (всё или ничего). Расчёт на реальном проекте — бэкенд на Laravel с фронтендом на Vue:

| Что | Режим | Токенов |
|---|---|---|
| Console/Commands, Trait, Models, Bitrix24, схема БД | полностью | ~73 000 |
| Http/Controllers, Report, middleware | скелет | ~20 000 |
| `resources/**` (Vue) | только дерево | ~1 500 |
| **Итого** | | **~95 000** против 287 000 |

Без потери информации: всё нужное на месте, про фронтенд модель знает, что он есть.

Скелет в v1 — регулярками (docblock + строка объявления), ~150 строк, ~80% эффекта AST.

### 8. Сканер секретов
Правила gitleaks. Текущий скрипт по маске `php, js, sql, txt` радостно выгрузит `.env` и конфиги с паролями. У repomix Secretlint включён по умолчанию — планка задана.

### 9. Манифест в шапке
Нумерованный список всех файлов + дерево. Не для красоты: это инструмент проверки. «Сколько файлов в манифесте и все ли у тебя есть» → за 10 секунд понятно, читает модель или ищет.

### 10. Вывод в Markdown
Дерево в шапке, каждый файл в ```-фенсе с путём. Модели разбирают такой формат лучше, чем разделители из дефисов.

### 11. Проверка промта против бандла — оригинальная фича
Отдельное поле: вставляете свой промт, инструмент вытаскивает из него упоминания файлов и терминов и показывает, какие есть в бандле, а каких нет. Нет ни у кого. Ловит ровно те промахи, из-за которых потом полдня споришь с моделью.

## Функционал v2

- `--since main` / `--since HEAD~5` — только файлы из диффа.
- `--clipboard` — сразу в буфер (Windows).
- `--split-output` — нарезка под вставку в чат по частям, первым куском манифест.
- Режим MCP-сервера.
- AST-скелет через tree-sitter (cgo + `go-tree-sitter`, queries копируются из repomix — MIT, с сохранением `third_party/repomix/LICENSE`; сборка под Linux через `zig cc`).

## Чего НЕ делать

- **AST-сжатие в v1.** Для сценария «выбираю пути руками» выигрыш скромный, а цена высокая.
- **Docker/dev-container для разработки.** Инструмент обходит ФС и поднимает UI с пикером по ней — в контейнере увидит ФС контейнера, пути не совпадут.
- **wazero-путь для tree-sitter** как стартовый. Недели работы в самой болезненной для отладки области.
- **Строить под окно 1M.** Окно есть, качества на нём нет, и оно дрейфует от обновлений провайдера.
