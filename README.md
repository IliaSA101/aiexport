# aiexport

Собирает исходники из нескольких папок в один файл для языковой модели. Один статический
бинарник: запустил — открылась форма в браузере, выбрал пути, нажал кнопку, получил файл.

Для обычного проекта с одним корнем эту задачу уже решает
[repomix](https://github.com/yamadashy/repomix). `aiexport` нужен там, где repomix слаб:

- **мультикорневые бандлы** — сборка из произвольных путей разных корней с человеческими
  подписями: модуль из одного проекта, документация из другого, кусок чужого кода из третьего;
- **режим на каждый путь** — одну папку целиком, другую только деревом, не включая содержимое;
- **честный отчёт о пропущенном** — что не попало в выгрузку и почему. Молчаливая потеря
  содержимого — главный способ, которым такие инструменты вредят: модель видит имя файла,
  считает, что содержимое ей показали, и делает выводы из пустоты;
- **ноль внешних зависимостей** — один исполняемый файл вместо установленного Node.js.

## Состояние

Ранняя версия, цикл 1: ядро, два режима на источник (`полностью` и `только дерево`),
счётчик токенов `o200k_base` с зонами, веб-интерфейс. Профили, глобы в конфиге, сканер
секретов, режим скелета и доступ по сети — следующие версии, см. `docs/ROADMAP.md`.

## Установка

Готовый бинарник — на странице Releases: https://github.com/IliaSA101/aiexport/releases
(ходите по этой ссылке, а не через поиск: он может привести на поддельный форк).

1. Скачать архив своей ОС и `SHA256SUMS`
   (`aiexport-ВЕРСИЯ-linux-amd64.tar.gz`, `…-darwin-arm64.tar.gz`, `…-windows-amd64.zip` и т. д.).
2. Сверить сумму в каталоге с загрузками:
   - Linux: `sha256sum -c SHA256SUMS --ignore-missing`;
   - macOS: `shasum -a 256 -c SHA256SUMS --ignore-missing`;
   - Windows (PowerShell): `Get-FileHash -Algorithm SHA256 .\aiexport-ВЕРСИЯ-windows-amd64.zip`
     и сравнить результат со строкой в `SHA256SUMS`.

   Сумма защищает от битой загрузки, а не от подмены: файл сумм лежит на той же странице.
3. Распаковать (`tar -xzf архив.tar.gz`, на Windows — «Извлечь всё»), перейти в каталог
   `cd aiexport-ВЕРСИЯ-OS-ARCH` и запустить `./aiexport` (на Linux и macOS именно с `./`:
   без него оболочка ищет команду в PATH).

Карантин macOS и SmartScreen обходить только после того, как сумма сошлась.
На macOS файл из браузера помечен карантином — снять: `xattr -d com.apple.quarantine ./aiexport`.
На Windows бинарник не подписан, поэтому SmartScreen при первом запуске предупредит:
«Подробнее» → «Выполнить в любом случае».

## Запуск

```
aiexport
```

Поднимает интерфейс на `http://127.0.0.1:8471` и открывает браузер. Слушает только
loopback: наружу инструмент не вешать, он читает произвольные файлы с диска. Другой порт —
`--port 8479`, без открытия браузера — `--no-browser`.

Без браузера:

```
aiexport export --src "full|Мой модуль|D:\projects\my-module" \
                --src "tree|Фронтенд|D:\projects\my-front" \
                --out bundle.md
```

Флаг `--src` повторяется, порядок флагов задаёт порядок секций в файле: самое важное
для вопроса ставьте последним. Формат — `режим|подпись|путь`, разделитель `|`,
потому что двоеточие занято буквой диска Windows. Режимы: `full`, `tree`.

Ещё: `--exclude` (глоб, повторяемый), `--no-gitignore`, `--max-size` (байт),
`--instructions` (текст в конец бандла), `--force` (заменить существующий файл вывода),
`--version`.

Существующий файл инструмент не затирает без `--force`, а в интерфейсе спрашивает
подтверждение: опечатка в имени не должна стоить вам файла.

## Что попадает в файл

1. Шапка с итогами: файлов, токенов, зона бюджета.
2. Манифест — нумерованный список всех включённых файлов. Это инструмент проверки:
   спросите модель, сколько файлов в манифесте и все ли у неё есть.
3. Дерево по каждому источнику.
4. Секция «что сознательно не включено» — с причинами. Без неё модель считает
   отсутствующий каталог несуществующим и предлагает создать его заново.
5. Содержимое файлов, каждый в своём фенсе с путём и подписью источника.

По умолчанию учитывается `.gitignore` каждого дерева плюс встроенный список
(`.git`, `node_modules`, `vendor`, `dist`, `build`, `.venv`, `__pycache__`, `.obsidian`).
Бинарные файлы отсекаются по NUL-байту, как это делает git, но UTF-16 с BOM сначала
декодируется: иначе содержимое терялось бы молча.

## Сборка

Нужен Go 1.26 и выше.

```bash
go build -ldflags "-X main.version=0.1.0" -o bin/aiexport ./cmd/aiexport
```

Windows:

```powershell
go build -ldflags "-X main.version=0.1.0" -o bin/aiexport.exe ./cmd/aiexport
```

Кросс-сборка под Linux и macOS — обычным `GOOS`/`GOARCH` с `CGO_ENABLED=0`,
архивы для выпуска собирает `scripts/release.sh`, подробности в `docs/RELEASE.md`.
